# Personal Portfolio Website

A responsive, static personal portfolio website built with pure HTML5 and CSS3.

## Project Structure

```
portfolio-website/
│
├── index.html          # Home Page
├── about.html          # About Page
├── skills.html         # Skills Page
├── projects.html       # Projects Page
├── contact.html        # Contact Page
├── offline.html        # Offline Fallback Page
│
├── css/
│   └── style.css       # Main Stylesheet
│
├── assets/
│   ├── images/         # Project images (currently placeholders)
│   └── icons/          # PWA Icons (SVG)
│
└── manifest.json       # PWA Manifest
```

## Features

- **No Frameworks**: Pure HTML/CSS.
- **Responsive**: Mobile-first design using Flexbox and Grid.
- **PWA Ready**: Includes `manifest.json` and `offline.html`.
- **Theme**: Blue and Gray color scheme.

## How to Run

1. Open the folder `portfolio-website`.
2. Double-click `index.html` to open it in your web browser.

## Customization

- Edit the HTML files to change the content.
- Update `css/style.css` to change variables (colors, fonts).
- Replace images in `assets/images/` with your own.
